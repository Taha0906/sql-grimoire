# SQL GRIMOIRE | The Query Wizard's Archive

این پروژه **وب‌سایت استاتیک** است، نه اپلیکیشن و نه پروژه سروری. طراحی، CSS و همه ۷۲ صفحه تصویری از فایل `SQL_GRIMOIRE_SOURCE (1).zip` حفظ شده‌اند. بخش «تالار تمرین جادوگر کوئری» به صفحه اصلی اضافه شده است.

## اجرای ساده در کامپیوتر

پوشه ZIP را کامل Extract کنید. روی فایل `index.html` دوبار کلیک کنید. اگر صفحات نمایش داده نشدند، بررسی کنید پوشه `pages` کنار `index.html` باشد. برای انتشار سایت، کل محتویات این پوشه باید در GitHub بارگذاری شود.

## انتشار رایگان در GitHub Pages

1. با حساب رایگان GitHub وارد https://github.com شوید.
2. از دکمه **New repository** مخزن جدیدی مانند `sql-grimoire` بسازید و گزینه **Public** را انتخاب کنید.
3. وارد مخزن شوید و **Add file → Upload files** را انتخاب کنید.
4. فایل `index.html`، فایل `sql-lab.js`، فایل `.nojekyll` و **پوشه کامل `pages` با همه ۷۲ تصویر** را در ریشه مخزن قرار دهید. راه راحت: کل محتویات پوشه استخراج‌شده را یک‌جا به صفحه Upload بکشید. سپس **Commit changes** بزنید.
5. به **Settings → Pages** بروید. در Source گزینه **Deploy from a branch** و در Branch گزینه **main** و **/(root)** را انتخاب و **Save** کنید.
6. نشانی سایت معمولاً شبیه `https://USERNAME.github.io/sql-grimoire/` است. نام کاربری خودتان را جایگزین `USERNAME` کنید. از بخش Pages گزینه **Visit site** را نیز می‌توانید بزنید.

**دقت:** برای پلن GitHub Free، مخزن منتشرشده باید عمومی باشد. تمام تصویرها و کدهای داخل سایت برای بازدیدکنندگان قابل دسترسی‌اند. داده‌های واقعی و خصوصی شرکت را در آن قرار ندهید.

## تمرین SQL چطور ارزیابی می‌شود؟

۱۰ مأموریت آموزشی وجود دارد. کاربر `SELECT` خود را وارد می‌کند. موتور کوچک و بدون وابستگی جاوااسکریپتی آن را روی جدول‌های فرضی `Practice.Products`، `Practice.Suppliers`، `Practice.Sales` و `Practice.Branches` اجرا می‌کند و **خروجی** را با خروجی پاسخ مرجع مقایسه می‌کند (برای بعضی پرسش‌ها ترتیب ردیف هم معیار است). جواب‌های مختلفی که خروجی یکسان دارند می‌توانند پذیرفته شوند.

این موتور **SQL Server کامل نیست** و فقط برخی امکانات `SELECT` از جمله `WHERE`، `LIKE`، `ORDER BY`، `TOP`، `COUNT`، `AVG`، `SUM`، `GROUP BY`، `HAVING` و `INNER JOIN` ساده را پیاده‌سازی می‌کند. `CTE`، `CASE`، Subquery، Window Functions و Stored Procedures در این نسخه اجرا نمی‌شوند. دستورات تغییر داده پذیرفته نمی‌شوند. ابزار اجرای کوئری واقعی روی دیتابیس شرکت نیست.

پیشرفت مأموریت‌ها، متن کد هر مأموریت، نشانک‌ها و یادداشت‌های قدیمی در حافظه محلی مرورگر (`localStorage`) ذخیره می‌شوند. حساب کاربری یا همگام‌سازی ابری وجود ندارد. پاک کردن داده‌های مرورگر یا استفاده از مرورگر/دستگاه دیگر ممکن است باعث از دست رفتن پیشرفت شود.

برای مطالعه اولیه، فونت‌ها از Google Fonts درخواست می‌شوند و در صورت قطع اینترنت فونت جایگزین سیستم استفاده می‌شود؛ هیچ کتابخانه JavaScript از CDN بارگیری نمی‌شود. همه ۷۲ تصویر در خود بسته موجودند.
